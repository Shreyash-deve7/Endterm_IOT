In Kafka consumer configuration, auto.offset.reset decides where the consumer starts reading when there is no saved offset for it (for example, a brand new consumer group). When set to earliest, the consumer reads from the very beginning of the partition, so it picks up all the old messages that are still stored in the topic. When set to latest, the consumer ignores the older messages and only reads new ones that arrive after it connects. In short, earliest is useful when you do not want to miss any past data, while latest is useful when you only care about messages coming in from now onward.
